Progress sharing & sync

This standalone HTML uses browser storage, so another person's browser cannot automatically see your changes. For collaboration, export/import a JSON file, or connect the app to a shared backend such as Supabase/Firebase.

Quick sharing

Generate a shareable progress payload. Send this JSON to the other person and they can use Import progress.

True shared progress

For real-time shared progress, deploy this HTML and connect its progress records to a database. Recommended structure: users → research_progress → role_id → status → notes → updated_at. Supabase is a simple option because the browser can read/write a hosted PostgreSQL database with authentication and row-level security.
